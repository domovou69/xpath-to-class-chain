XPath to Class Chain

Appium iOS XPath in, -ios class chain out, or the reason there is none. Runs in your browser with the same code as the npm package.

npm GitHub Reference Results
Examples:
exact: same elements, same order. close: converts, with a warning about a difference. skipped: no exact class chain; the reason says why. Checked with Appium 3.8.0, appium-xcuitest-driver 12.16.0 and WDA 16.14.1; older versions were not checked.
